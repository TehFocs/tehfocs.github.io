DemoLoop
Put your video (.mp4 / .mov / .m4v) into this folder. It starts by itself within a few seconds.
Optional: create an empty file named "fill" here to crop the video to the full screen.
Exit demo: tap 5 times in the top-left corner of the screen.

Положи видео (.mp4 / .mov / .m4v) в эту папку, оно запустится само.
Пустой файл с именем "fill" заставит видео занять весь экран (с обрезкой).
Выход из демо: 5 быстрых тапов в левом верхнем углу экрана.
